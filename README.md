# HTML Registration Form

This project is a complete and interactive student registration form built using HTML5 as part of the Web Development 1 course.

## Features
- **Personal Information:** Full Name, Email, Password confirmation, and Date of Birth with built-in HTML5 validation.
- **Contact Details:** Phone number (with pattern validation), Address (Textarea), and a City dropdown menu.
- **User Preferences:** Gender selection, Interests checkboxes, and a Skill Level range slider.
- **File Upload:** Profile picture upload supporting images only (`accept="image/*"`).
- **Terms & Submission:** Required Terms and Conditions agreement checkbox with Submit and Reset buttons.

## Technologies Used
- HTML5 (Semantic elements, Forms, Validation)
- Git & GitHub (Version Control)
